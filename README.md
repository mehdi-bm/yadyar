# یادیار پارسیک (Yadyar)

اپلیکیشن «سازمان‌دهنده شخصی» برای کاربران ایرانی — یادداشت/یادآور، مدیریت اشتراک و قبض، و لیست خرید خانواده.
این اپ کاملاً **آفلاین** کار می‌کند: بدون سرور اختصاصی، بدون هزینه نگهداری. تمام داده‌های شما به‌صورت محلی روی گوشی (SQLite) ذخیره می‌شوند و هیچ‌وقت به بیرون ارسال نمی‌شوند.

## دانلود

آخرین نسخه را از بخش [Releases](../../releases/latest) دانلود کنید (فایل `app-release.apk`).
اپ فقط از منابع خارج از گوگل‌پلی (نصب مستقیم/کافه‌بازار) قابل نصب است؛ در گوشی باید گزینه «نصب از منابع ناشناس» برای مرورگر یا فایل‌منیجر فعال باشد.

## امکانات

### یادداشت و یادآور
- ثبت یادداشت با عنوان، متن و تگ آزاد؛ جستجوی زنده و فیلتر بر اساس تگ
- یادآور اختیاری برای هر یادداشت با تاریخ/ساعت شمسی و تکرار (بدون تکرار/روزانه/هفتگی/ماهانه)
- سنجاق کردن یادداشت‌های مهم و مرتب‌سازی بر اساس نزدیک‌ترین یادآور، آخرین ویرایش، تاریخ ایجاد یا الفبا
- اعلان محلی واقعی برای هر یادآور (بدون نیاز به اینترنت)

### اشتراک و قبض
- ثبت قبض/اشتراک با مبلغ (با جداکننده هزارگان زنده)، دسته‌بندی، تاریخ سررسید و تکرار (یک‌بار/ماهانه/سالانه)
- وضعیت رنگی خودکار: پرداخت‌شده، سررسید نزدیک، عقب‌افتاده
- امکان محدود کردن تعداد دفعات تکرار برای اقساط (مثلاً وام ۱۲ ماهه)؛ با پرداخت هر قسط شمارنده کم می‌شود
- تاریخچه پرداخت‌ها و نمودار ستونی هزینه ۶ ماه اخیر
- یادآوری خودکار چند روز قبل از سررسید (قابل تنظیم)

### لیست خرید خانواده
- چند لیست خرید مستقل، هرکدام با آیتم‌های دسته‌بندی‌شده (میوه و سبزیجات، لبنیات، بهداشتی و ...)
- آیتم‌های خریداری‌شده به‌صورت خط‌خورده در پایین لیست جمع می‌شوند
- پاک کردن سریع همه آیتم‌های خریداری‌شده با یک دکمه

### داشبورد
- خلاصه یک‌نگاه: یادآورهای امروز، قبض‌های معوق، آیتم‌های خرید باقی‌مانده
- یادآورهای امروز/فردا، قبض‌های نزدیک سررسید و لیست‌های خرید فعال، همه در یک صفحه

### پشتیبان‌گیری و بازیابی
- تهیه نسخه پشتیبان کامل از پایگاه‌داده با یک ضربه و اشتراک‌گذاری آن (گوگل‌درایو، تلگرام و ...)
- بازیابی از فایل پشتیبان محلی یا خارجی، با اعتبارسنجی فایل پیش از جایگزینی
- پیش از هر بازیابی، به‌صورت خودکار یک نسخه پشتیبان امنیتی از وضعیت فعلی گرفته می‌شود تا در صورت انتخاب فایل اشتباه، داده‌ای از دست نرود

### تبلیغات و پشتیبانی (اختیاری، نیازمند پیکربندی سرویس پارسیک)
- بنر تبلیغاتی در داشبورد با چرخش خودکار و ثبت کلیک ناشناس
- فرم درخواست تبلیغ و فرم گزارش خطا برای ارتباط مستقیم با تیم پشتیبانی

### ظاهر
- تم روشن/تیره/خودکار (هماهنگ با سیستم)، قابل تغییر با یک ضربه
- طراحی کاملاً راست‌به‌چپ و فارسی با فونت وزیرمتن

## پشته فناوری (Tech Stack)

| هدف | پکیج |
| --- | --- |
| پایگاه‌داده محلی | `sqflite` |
| مسیرهای فایل سیستم | `path_provider` |
| ذخیره‌سازی ساده کلید-مقدار | `shared_preferences` |
| اعلان‌های محلی (یادآورها) | `flutter_local_notifications` + `timezone` + `flutter_timezone` |
| مدیریت state | `provider` |
| نمودار و آمار | `fl_chart` |
| فرمت اعداد/تاریخ | `intl` |
| تقویم و انتخابگر تاریخ شمسی | `shamsi_date` + `persian_datetime_picker` |
| اشتراک‌گذاری فایل (پشتیبان‌گیری) | `share_plus` |
| انتخاب فایل (بازیابی) | `file_picker` |
| باز کردن لینک تبلیغ | `url_launcher` |

## ساختار پروژه

```
lib/
├── main.dart                # نقطه ورود اپ + اسکلت ناوبری ۴ تب
├── constants/                # مقادیر ثابت (نام اپ، رنگ‌ها و ...)
├── config/                   # پیکربندی سرویس تبلیغات (از --dart-define)
├── models/                   # Note, Reminder, Subscription, ShoppingList, ShoppingItem, AdBanner, ...
├── database/                 # DatabaseHelper: راه‌اندازی، جدول‌ها و مهاجرت (migration) sqflite
├── repositories/              # لایه دسترسی به داده برای هر مدل
├── providers/                 # مدیریت state با Provider (ChangeNotifier)
├── services/                  # سرویس‌های شبکه (تبلیغات، پشتیبانی) و پشتیبان‌گیری
├── screens/                   # صفحات اصلی اپ
│   ├── notes/                 # یادداشت/یادآور
│   ├── bills/                  # اشتراک و قبض
│   ├── shopping/                # لیست خرید خانواده
│   ├── backup/                  # پشتیبان‌گیری و بازیابی
│   └── support/                  # درخواست تبلیغ و گزارش خطا
├── widgets/                    # ویجت‌های قابل استفاده مجدد (شامل بنر تبلیغاتی)
├── theme/                      # تعریف ThemeData، رنگ‌ها و تایپوگرافی
└── utils/                      # توابع کمکی (تبدیل تاریخ شمسی، فرمت‌دهی و ...)
```

## اجرای پروژه

```bash
flutter pub get
flutter run
```

برای نمایش تبلیغات، فایل `dart_define.example.json` را به `dart_define.json`
کپی کنید و کلیدهای واقعی سرویس را در فایل محلی وارد کنید. سپس اجرا کنید:

```bash
flutter run --dart-define-from-file=dart_define.json
```

تنظیم اجرای `Yadyar` در VS Code این فایل را خودکار می‌خواند. برای ساخت APK نیز
از `flutter build apk --dart-define-from-file=dart_define.json` استفاده کنید.
مقدار `ADS_SECTION_CODE` باید با جایگاه فعال روی سرور تبلیغات مطابقت داشته
باشد و `ADS_APP_NAME` باید دقیقاً همان کد اپلیکیشن ثبت‌شده در پنل مدیریت
تبلیغات باشد. مقدار خالی سکشن، همه جایگاه‌های مجاز را درخواست می‌کند.
پس از تغییر تنظیمات، اجرای برنامه را کامل متوقف و دوباره شروع کنید؛ Hot Reload
مقادیر `dart-define` را تغییر نمی‌دهد. فایل `dart_define.json` محلی است و نباید
در Git ثبت شود.
